# 技能库

把你的处理经验、话术、业务规则写成 `.md` 文件放在这个目录里，Agent 需要时会自己读取。

## 怎么用

1. 在管理后台的 **技能库** 页面新建，或直接在这里放 `.md` 文件
2. 在 **系统提示词** 里告诉 Agent 什么时候该查技能，例如：
   > 遇到退货、物流、纠纷类问题，先用 `read_skill` 查一下对应技能再回答。
3. Agent 会在需要时调用 `read_skill` 工具读取全文

## 写法建议

- 文件名就是技能名（工具调用时用这个名字，不带 `.md`）
- 第一行非标题文字会作为「描述」显示在工具列表里，方便 Agent 判断该不该读
- 内容写**可执行的步骤和话术**，不要写散文

## 示例

```markdown
<!-- desc: 买家要求退货时的标准处理流程 -->
# 退货处理

1. 先安抚：「可以的，我帮你走一下退货流程～」
2. 问清原因，记录到回复里
3. 引导买家在订单页点「申请退款」，选对应原因
4. 商品类：让买家拍一张问题照片
5. 不要承诺「马上退」，统一回复「我这边提交给店主确认，稍后处理」
```

`<!-- desc: ... -->` 是可选的描述注释，管理后台会自动读写它。
